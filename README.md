# LENA — Dress Roomshow

تطبيق عربي RTL لإدارة وتشغيل معرض واحد لفساتين ومستلزمات المناسبات، بقاعدة Supabase مركزية وواجهة Web/PWA.

## العمل الحالي

- [قائمة التنفيذ وعلامات الإنجاز](docs/EXECUTION_CHECKLIST.md)
- [المعمارية المستهدفة](docs/TARGET_CODE_ARCHITECTURE.md)
- [خط أساس التفكيك والمكونات المختلطة](docs/ARCHITECTURE_BASELINE.md)

أي وكيل أو مطور يبدأ من أول بند غير مكتمل وغير محجوب داخل `EXECUTION_CHECKLIST.md`. لا يُعلّم أي بند كمكتمل إلا بعد دمجه في `main` ونجاح الفحوصات المطلوبة.

## هدف المنظومة

LENA يربط الحقيقة المادية والتجارية والمالية والتشغيلية للمعرض في نظام واحد:

- حالة كل عنصر ومكانه ومدى جاهزيته.
- العميلة والحجز والمواعيد والتسليم والاسترجاع.
- التحصيل والعربون والغرامات والاسترداد والبيع والمصروفات.
- الفحص والغسيل والصيانة بعد الإرجاع.
- إقفال اليومية والتقارير وسجل التدقيق.
- النسخ الاحتياطي والاستعادة وتشغيل PWA.

تفاصيل منطق الأعمال وحالات العناصر والحجوزات والحركات المالية موجودة في [`docs/BUSINESS_MODEL.md`](docs/BUSINESS_MODEL.md).

## نطاق المنتج

- المخزون بأنواعه: فساتين، إكسسوارات، حقائب، أحذية، طرح، وأخرى.
- العملاء والحجوزات والمواعيد والتسليم والاسترجاع.
- المدفوعات والعربون والغرامات والمصروفات والبيع المباشر.
- التقارير وإقفال اليومية وسجل التدقيق والنسخ الاحتياطي.
- منع تعارض الحجوزات وفترة تجهيز قابلة للضبط.
- صفحة عرض عامة للمخزون قابلة للتخصيص.

النسخة الحالية مخصصة لمعرض واحد فقط. تدعم حسابات admin/staff ومزامنة أجهزة المعرض، ولا تشمل SaaS أو تعدد الفروع أو الدفع الإلكتروني.

## التخزين والتشغيل

- سطح الإصدار الرسمي هو تطبيق الويب وPWA فقط؛ القرار موثق في [ADR 0001](docs/adr/0001-web-pwa-supabase-only.md).
- Supabase/PostgreSQL هو مصدر الحقيقة المركزي الفعلي. لا تفتح الشاشات التشغيلية قبل تحميل النسخة المركزية.
- `localStorage` ذاكرة مؤقتة للواجهة فقط؛ كل أمر يُعتمد ذريًا عبر RPC بمفتاح idempotency ورقم مراجعة، ويُلغى محليًا إذا رفض الخادم الحفظ أو اكتشف تعارضًا.
- لا تُقبل كتابات تشغيلية دون اتصال. يظل غلاف PWA وصفحة الدخول قابلين للتحميل، ثم يتطلب العمل اتصالًا آمنًا بالخادم.
- كود سطح المكتب (Tauri) محفوظ مؤقتًا للتوافق والاسترجاع التاريخي، ومستبعد من بناء الويب الرسمي.

## التقنية

React، TypeScript، Vite، Tailwind CSS، React Router، PWA، وSupabase/PostgreSQL. (يُحتفظ بـ Tauri 2 وSQLite مؤقتًا خارج نطاق الإصدار الرسمي — راجع [ADR 0001](docs/adr/0001-web-pwa-supabase-only.md).)

## التحقق

```bash
npm ci
npm test
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

لفحص بيئة سطح المكتب القديمة (خارج نطاق الإصدار الرسمي — راجع [ADR 0001](docs/adr/0001-web-pwa-supabase-only.md)):

```bash
npm run tauri -- info
```

`tauri -- info` يصف البيئة فقط ولا يُعد دليلًا على نجاح Native Build.
