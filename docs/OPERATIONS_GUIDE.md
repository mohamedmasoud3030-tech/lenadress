# دليل التشغيل — LENA

دليل عملي لموظفة المعرض ولمن يثبّت النظام. النظام محلي بالكامل: لا يوجد خادم،
ولا حساب مستخدم، ولا دفع إلكتروني. كل البيانات على الجهاز نفسه.

## 1. التثبيت

### المتصفح / PWA

1. افتحي رابط التطبيق.
2. من قائمة المتصفح اختاري «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3. بعد التثبيت يعمل التطبيق بدون إنترنت، والخط العربي مضمّن داخل التطبيق.

### سطح المكتب (Windows)

```bash
npm ci
npm run build
npm run tauri build
```

ثم ثبّتي الملف الناتج. البيانات تُحفظ محلياً وتُستعاد عند إعادة تشغيل التطبيق.

## 2. أول تشغيل على قاعدة فارغة

النظام يبدأ **فارغاً تماماً**، ولا يضيف أي بيانات وهمية من تلقاء نفسه.

الترتيب الموصى به:

1. **الإعدادات** → بيانات المعرض وأيام التجهيز (Preparation Buffer).
2. **المخزون** → أضيفي القطع. الكود يُولَّد تلقائياً ولا يتكرر أبداً.
3. **العملاء** → أضيفي العميلات.
4. ابدئي الحجوزات.

## 3. البيانات التجريبية

من **الإعدادات** يمكن تحميل بيانات تجريبية بضغطة صريحة وتأكيد. قبل التحميل
يأخذ النظام نسخة من حالتك الحالية، ويمكن التراجع لاستعادتها بالكامل.

لا تُحمَّل البيانات التجريبية تلقائياً في أي حالة.

## 4. الدورة اليومية

| الخطوة | الصفحة | ملاحظة مهمة |
| --- | --- | --- |
| إضافة قطعة | المخزون | الكود لا يُعاد استخدامه حتى بعد الحذف |
| إضافة عميلة | العملاء | — |
| إنشاء حجز | الحجوزات | يُرفض التداخل مع حجز آخر أو مع أيام التجهيز |
| تحصيل | المدفوعات | الضغط مرتين لا يُحصّل المبلغ مرتين |
| تسليم | التسليم والاسترجاع | حالة القطعة تصبح «مؤجر» |
| استرجاع | التسليم والاسترجاع | القطعة **لا** تعود «متاح» مباشرة، بل تذهب للفحص أو الغسيل أو الصيانة |
| خدمة | طابور الخدمة | عند الإنهاء تحدّدين حالة القطعة صراحة، والتكلفة تُسجَّل كمصروف على القطعة |
| بيع | المبيعات | كل بيع فاتورة، حتى البيع السريع |
| مرتجع بيع | المبيعات | مرتبط ببند الفاتورة، ولا يتكرر، والقطعة تذهب للفحص |
| مصروف | المصروفات | يمكن ربطه بقطعة فتدخل في ربحيتها |
| إقفال اليومية | إقفال اليومية | بعده تُرفض أي حركة مالية لنفس التاريخ |
| التقارير | التقارير | العربون المسترد التزام، وليس إيراداً |

## 5. المعنى المالي (مهم)

- **العربون القابل للرد التزام على المعرض، وليس ربحاً.** يظهر منفصلاً في التقارير.
- **العربون المحتجز فقط** (لتغطية تأخير أو ضرر) هو الذي يُحتسب دخلاً.
- **المبلغ المحصّل ليس ربحاً**: «صافي حركة النقد» و«الدخل المعترف به» رقمان مختلفان.
- **حجز لم يُنفَّذ لا يُحتسب إيراداً** مهما كان سعره المدرج.
- ربحية القطعة تعتمد على الأموال المتحققة فعلياً، ناقصاً مصروفاتها ومرتجعاتها.

## 6. النسخ الاحتياطي والاستعادة

من **الإعدادات**:

- **تصدير نسخة**: يشمل كل السجلات والصور وعدّادات الأكواد وسجل التدقيق.
- **استيراد نسخة**: يُفحص الملف بالكامل **قبل** تعديل أي بيانات. الملف غير
  الصالح يُرفض ولا يُمس شيء. لو فشلت العملية في منتصفها تعود بياناتك السابقة
  كما كانت تماماً، ولا تبقى استعادة نصفية.

**التوصية:** صدّري نسخة في نهاية كل يوم عمل، واحفظيها خارج الجهاز.

## 7. الترقية والرجوع

1. صدّري نسخة احتياطية قبل الترقية.
2. ثبّتي الإصدار الجديد.
3. افتحي التطبيق وتأكدي من ظهور بياناتك.
4. للرجوع: ثبّتي الإصدار السابق ثم استوردي النسخة الاحتياطية.

## 8. حل المشاكل الشائعة

| المشكلة | الحل |
| --- | --- |
| لا تفتح نافذة الطباعة | اسمحي بالنوافذ المنبثقة لهذا التطبيق ثم أعيدي المحاولة |
| رسالة تعذر الحفظ محلياً | مساحة التخزين ممتلئة: صدّري نسخة، ثم رحّلي الصور إلى IndexedDB من الإعدادات |
| الكاميرا لا تعمل للباركود | استخدمي الإدخال اليدوي للكود؛ يعمل دائماً |
| لا يمكن حذف قطعة أو عميلة | لها تاريخ تشغيلي أو مالي: استخدمي الأرشفة، فالحذف سيُفقد التقارير |
| لا يمكن تسجيل حركة مالية | اليومية مقفلة لهذا التاريخ: أعيدي فتحها بسبب مسجّل |
